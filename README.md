# CROPYFTY - A MOBILE-BASED MARKETPLACE FOR ENHANCING DIRECT AGRICULTURAL TRADE BETWEEN FARMERS AND CONSUMERS

## Description
Cropyfty is a mobile-based aplication that allows users[farmers] to connect with clients[buyers] and focuses on speed,simplicity and usability

## Features
- User Authentication
- File Uploads[photos/videos]
- Mobile first
- CRUD operations[upload, edit, delete]
- Secure data storage

## Tech Stack
**Frontend:**
- JSX
- TailwindCSS
- ReactJS
- TypeScript

**Backend:**
- Python(Flask)

**Database:**
- MySQL
- phpMyAdmin

**Tools:**
- Git & Github
